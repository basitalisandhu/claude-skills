Claude Code Setup Tooling

Fourteen skills that keep a Claude Code setup safe and tidy: review a third-party skill or plugin before installing it (skill-scan-gate, cc-plugin-lock and an offline inventory), lint SKILL.md front matter and fix its quoting, score descriptions against labelled prompts, estimate what a project loads on every turn, merge least-privilege permission rules and test them with claude-perm-sim, review the sandbox settings across scopes and flag what leaves it open, list the tool calls that would stop an unattended run on a permission prompt, show what each subagent can reach, add up the API usage in session transcripts and show which part moved, count shell commands that failed because of zsh, PowerShell or the Windows length limit, check what each compaction summary dropped, scaffold and test hooks with cc-hooks, find skills that collide or shadow each other, and find what breaks on other hosts and operating systems. Standard-library scripts, no network.

Plugin cc-setup-tooling, version 0.5.0, 14 skills, MIT licence. Source: claude-code-tooling-skills. Synced 2026-10-26.

Install

In Claude Code, add the marketplace and install the plugin:

/plugin marketplace add basitalisandhu/claude-skills
/plugin install cc-setup-tooling@claude-skills

Or copy the skill files into ~/.claude/skills/ from a clone:

git clone https://github.com/basitalisandhu/claude-skills
cd claude-skills
python3 install.py --user --only cc-setup-tooling

Plugin README

Skills that keep a Claude Code setup safe and tidy, each with a tested standard-library Python script. Install with /plugin marketplace add basitalisandhu/claude-code-tooling-skills and then /plugin install cc-setup-tooling@claude-code-tooling-skills. Skills appear as /cc-setup-tooling:<skill>, and Claude also invokes them on its own when a request matches a skill's description.

SkillScriptUse it to

Requirements: Python 3.10 or newer on PATH as python3. The scripts read local files only: no network access, no third-party packages. The separate tools the skills drive (skill-scan-gate, cc-plugin-lock, cc-hooks, claude-perm-sim, claude-mcp-allow) are installed and run by the user; each skill says what to do when one is missing.
