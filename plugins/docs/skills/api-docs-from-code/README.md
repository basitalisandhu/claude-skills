# api-docs-from-code

Generate an API reference from source: a bundled script extracts Python docstrings and JavaScript or TypeScript JSDoc into Markdown or JSON, lists public functions and classes with no docstring and gives a documentation coverage number; then fill the gaps and wire it into the docs build.

Use it when asked to "document this module" or package, when the reference docs are out of date, or which public functions lack docstrings.
Not for OpenAPI specs (api-contract-review) and not a replacement for Sphinx, mkdocstrings or TypeDoc where already used.

Claude follows [SKILL.md](SKILL.md); it is part of the `docs` plugin (`/plugin install docs@claude-dev-skills`).

## Run the script

From a clone of the repository (Python 3.11 or newer, standard library only):

```bash
python3 plugins/docs/skills/api-docs-from-code/scripts/extract_docs.py tests/fixtures/api-docs-from-code/geometry.py
```

Inside Claude Code the skill runs `extract_docs.py` from `${CLAUDE_PLUGIN_ROOT}/skills/api-docs-from-code/scripts/`; `--help` lists every option.
