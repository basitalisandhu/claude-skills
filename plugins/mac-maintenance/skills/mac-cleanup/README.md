# mac-cleanup

Free disk space and speed up a Mac safely: survey it read-only, clear only what programs recreate (npm, Xcode and other package and build caches, Docker build cache, old logs), and write a decision list for everything else.

Not for Windows or Linux, malware scans, or deleting user files without an explicit yes.

How Claude runs it, step by step: [SKILL.md](SKILL.md). Without `--apply` nothing changes; with it, only caches and logs that programs recreate are removed, and everything else goes on a written decision list for you.

## Try it

From the repository root, on a synthetic home folder (your own files are not touched):

```bash
python3 scripts/demo_home.py demo-home
python3 plugins/mac-maintenance/skills/mac-cleanup/scripts/safe_clean.py --home demo-home --tmpdir demo-home/tmp --no-commands --only npm-cache,old-logs,xcode-derived-data,chrome-cache
```

This is the dry run of the safe tier; nothing changes until `--apply`. The survey (`mac_survey.py`) reports disk, caches, apps and memory for the same home but its numbers depend on the machine, so it has no fixed sample here. `safe_clean.py --list-actions` lists every action.
