# mac-duplicate-finder

Find byte-for-byte duplicate files in a Mac's user folders, report the largest groups and folders that mirror each other, and move verified suffix copies, the (1) copies of videos and photos (IMG_1 (1).MOV next to an identical IMG_1.MOV), to a dated Trash folder after a second hash check.

Not for near-duplicates such as resized or re-encoded images, the Photos library, or deleting anything outright.

How Claude runs it, step by step: [SKILL.md](SKILL.md). Nothing is deleted: only verified suffix copies move to a dated Trash folder, and only with `--trash-suffix-copies`.

## Try it

From the repository root, on a synthetic home folder (your own files are not touched):

```bash
python3 scripts/demo_home.py demo-home
python3 plugins/mac-maintenance/skills/mac-duplicate-finder/scripts/find_dupes.py --home demo-home --quiet
```

Add `--trash-suffix-copies` to move the `(1)` copy into a dated Trash folder after a second hash check; the original stays.
