# mac-app-leftovers

Find what uninstalled apps left behind on a Mac (Application Support and container folders, caches, preferences, saved state, logs, and login items or launch agents that point at nothing), deciding what is installed from app bundles, PATH, Homebrew and Spotlight, and move only the candidates you name into a dated Trash folder.

Not for uninstalling apps, Apple's own folders, or judging whether a command-line tool's data is wanted.

How Claude runs it, step by step: [SKILL.md](SKILL.md). Nothing is deleted: only the candidates you name move to a dated Trash folder.

## Try it

From the repository root, on a synthetic home folder (your own files are not touched):

```bash
python3 scripts/demo_home.py demo-home
python3 plugins/mac-maintenance/skills/mac-app-leftovers/scripts/app_leftovers.py --home demo-home --apps-dir demo-home/Applications --no-commands
```

On your own Mac, tools on your `PATH` and in Homebrew also count as installed, and launch agents in `/Library` are checked too, so the list can differ. Add `--trash ID,...` to move named candidates into a dated Trash folder.
