# connector-register

Checks the approved register of MCP servers, connectors and plugins: every entry has an owner, purpose, data classification, permissions and review date, and saved tool listings and manifests match it.

How to export the inputs, run it and read the result: [SKILL.md](SKILL.md). Every option: `python3 scripts/connector_register.py --help`.

## Sample

Run from the repository root on the bundled synthetic examples (every name, address and id in them is invented). Exit code 1 (something needs a person).

```bash
python3 plugins/agent-identity-governance/skills/connector-register/scripts/connector_register.py plugins/agent-identity-governance/examples/register.yaml --tools plugins/agent-identity-governance/examples/tools --manifests plugins/agent-identity-governance/examples/manifests --as-of 2026-10-05
```
