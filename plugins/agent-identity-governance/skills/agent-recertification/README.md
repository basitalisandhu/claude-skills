# agent-recertification

Prepares the quarterly recertification of agent and workload identities: one review sheet per owner and a tracking CSV, flagging identities never attested, stale attestations, owners who left and removals not done.

How to export the inputs, run it and read the result: [SKILL.md](SKILL.md). Every option: `python3 scripts/agent_recertification.py --help`.

## Sample

Run from the repository root on the bundled synthetic examples (every name, address and id in them is invented). Exit code 1 (something needs a person).

```bash
python3 plugins/agent-identity-governance/skills/nhi-inventory/scripts/nhi_inventory.py plugins/agent-identity-governance/examples/exports --as-of 2026-10-05 --json --out inventory.json
python3 plugins/agent-identity-governance/skills/agent-recertification/scripts/agent_recertification.py inventory.json --attestations plugins/agent-identity-governance/examples/attestations.csv --users plugins/agent-identity-governance/examples/users.json --as-of 2026-10-05
```
