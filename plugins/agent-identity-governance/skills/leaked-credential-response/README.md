# leaked-credential-response

Responds to a leaked agent credential: what it could reach, what was done with it after the leak time, which credentials to replace first, and an evidence folder with SHA-256 hashes.

How to export the inputs, run it and read the result: [SKILL.md](SKILL.md). Every option: `python3 scripts/leaked_credential_response.py --help`.

## Sample

Run from the repository root on the bundled synthetic examples (every name, address and id in them is invented). Exit code 1 (something needs a person).

```bash
python3 plugins/agent-identity-governance/skills/nhi-inventory/scripts/nhi_inventory.py plugins/agent-identity-governance/examples/exports --as-of 2026-10-05 --json --out inventory.json
python3 plugins/agent-identity-governance/skills/leaked-credential-response/scripts/leaked_credential_response.py inventory.json --identity aws-user:ci-deployer --credential MPLE --leaked-at 2026-10-02T01:30:00Z --cloudtrail plugins/agent-identity-governance/examples/logs/cloudtrail.json
```
