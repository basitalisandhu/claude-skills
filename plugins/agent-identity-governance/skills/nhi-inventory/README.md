# nhi-inventory

Lists every non-human identity agents and automations run as, across Entra ID (with Agent ID), AWS IAM, GitHub and a hand-kept register, with owner, last use, credential count and oldest credential, and flags the ownerless and the unused.

How to export the inputs, run it and read the result: [SKILL.md](SKILL.md). Every option: `python3 scripts/nhi_inventory.py --help`.

## Sample

Run from the repository root on the bundled synthetic examples (every name, address and id in them is invented). Exit code 1 (something needs a person).

```bash
python3 plugins/agent-identity-governance/skills/nhi-inventory/scripts/nhi_inventory.py plugins/agent-identity-governance/examples/exports --as-of 2026-10-05
```
