# credential-expiry-radar

Finds secrets, certificates, access keys and tokens that have expired or soon will, across Entra apps and Agent ID blueprints, AWS IAM, GitHub tokens and a CSV of other keys, bucketed at 7, 30 and 90 days with an action list per owner.

How to export the inputs, run it and read the result: [SKILL.md](SKILL.md). Every option: `python3 scripts/credential_expiry_radar.py --help`.

## Sample

Run from the repository root on the bundled synthetic examples (every name, address and id in them is invented). Exit code 1 (something needs a person).

```bash
python3 plugins/agent-identity-governance/skills/credential-expiry-radar/scripts/credential_expiry_radar.py plugins/agent-identity-governance/examples/exports --as-of 2026-10-05
```
