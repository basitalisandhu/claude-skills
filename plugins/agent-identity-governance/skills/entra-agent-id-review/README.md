# entra-agent-id-review

Reviews the Entra identities AI agents use: owner or sponsor, permissions (including those inherited from an Agent ID blueprint), credentials, redirect URIs and Conditional Access cover, with high-risk permissions from a fixed list.

How to export the inputs, run it and read the result: [SKILL.md](SKILL.md). Every option: `python3 scripts/entra_agent_review.py --help`.

## Sample

Run from the repository root on the bundled synthetic examples (every name, address and id in them is invented). Exit code 1 (something needs a person).

```bash
python3 plugins/agent-identity-governance/skills/entra-agent-id-review/scripts/entra_agent_review.py plugins/agent-identity-governance/examples/exports --as-of 2026-10-05
```
