# agent-action-timeline

Puts what one agent identity did in time order from saved sign-in, audit, CloudTrail, GitHub and application logs, and flags bursts, first-seen actions and actions outside an allow list.

How to export the inputs, run it and read the result: [SKILL.md](SKILL.md). Every option: `python3 scripts/agent_action_timeline.py --help`.

## Sample

Run from the repository root on the bundled synthetic examples (every name, address and id in them is invented). Exit code 1 (something needs a person).

```bash
python3 plugins/agent-identity-governance/skills/agent-action-timeline/scripts/agent_action_timeline.py --identity ci-deployer --cloudtrail plugins/agent-identity-governance/examples/logs/cloudtrail.json --allow-list plugins/agent-identity-governance/examples/logs/allow.txt
```
