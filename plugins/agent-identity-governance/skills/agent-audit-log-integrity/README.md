# agent-audit-log-integrity

Seals an agent's audit log as a SHA-256 or HMAC hash chain, verifies it later for edited, deleted, inserted or reordered lines and truncation, and lists actions the log never recorded.

How to export the inputs, run it and read the result: [SKILL.md](SKILL.md). Every option: `python3 scripts/audit_chain.py --help`.

## Sample

Run from the repository root on the bundled synthetic examples (every name, address and id in them is invented). Exit code 1 (something needs a person).

```bash
python3 plugins/agent-identity-governance/skills/agent-audit-log-integrity/scripts/audit_chain.py verify plugins/agent-identity-governance/examples/audit/agent-actions.tampered.jsonl --head-file plugins/agent-identity-governance/examples/audit/head.txt
```

Output, as printed:

````markdown
# Audit log integrity

Log: agent-actions.tampered.jsonl. Lines: 5, sealed: 5, sequence 0 to 5.
Result: NOT intact (3 problem(s)).
Head now: 5:f066fa27ec9eebaa1d5f09183ae0e768c8d91793ec11e8225e494b8c085759d2

## Findings

- hash-mismatch (line 3): sequence 2: content does not match its hash (edited, or the wrong key)
- seq-gap (line 5): sequence jumps from 3 to 5: 1 line(s) missing
- prev-mismatch (line 5): does not link to the line before it: a line before it was removed or edited
````
